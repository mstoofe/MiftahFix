MiftahFix - سجل التغييرات
=========================

الإصدار 1.1.0
-------------
ميزات جديدة:
- تصحيح آخر ما كتبته بدون تحديد: اكتب ثم اضغط الاختصار (Ctrl + Shift + Space)
  فيُحذف ما كتبته باللغة الخاطئة ويُكتب باللغة الصحيحة. اضغط مرة أخرى للتراجع.
  إذا كان هناك نص محدد بالماوس أو بـ Shift + الأسهم فسيُصحح النص المحدد كالسابق.
- تبديل لغة لوحة المفاتيح تلقائياً بعد التصحيح لتكمل الكتابة باللغة الصحيحة.
- كشف الكتابة بلغة خاطئة أثناء الكتابة، بثلاثة أوضاع في الإعدادات > التحويل:
  متوقف / تنبيهي فقط (افتراضي) / تصحيح تلقائي.

إصلاحات:
- الاختصار العام صار يحترم "طريقة التحويل" المختارة بدل التحويل التلقائي دائماً.
- انتظار رفع جميع مفاتيح الاختصار (Alt و Win والمفتاح المختار) وليس Ctrl و Shift فقط.
- الحفاظ على كل محتوى الحافظة (صور، ملفات، نص منسق) وليس النص فقط.
- السجل يعرض مصدر التصحيح الجديد: "تصحيح ما كُتب" و"تصحيح تلقائي".
- خيار "التحقق من التحديثات" صار يعمل فعلاً: يتحقق من صفحة GitHub Releases
  (mstoofe/MiftahFix) بعد بدء التشغيل بثوانٍ، ويظهر إشعار عند وجود إصدار أحدث.
  وأضيف زر "التحقق من التحديثات" في نافذة "حول".
- منع تشغيل نسختين من البرنامج: فتحه مرة ثانية يُظهر النافذة المفتوحة.
- أيقونة البرنامج الحقيقية بجانب الساعة بدل أيقونة Windows العامة.
- خيار "إيقاف التصحيح مؤقتاً / استئناف" في قائمة أيقونة البرنامج (مفيد للألعاب وكلمات المرور).
- رسالة واضحة عند محاولة التصحيح داخل برنامج مفتوح كمسؤول.
- ظهور سبب فشل التصحيح كإشعار عندما يكون البرنامج في الخلفية.
- المثبّت: كان يحذف خيار "التشغيل مع Windows" عند كل تحديث، وكانت رسالة حذف
  الإعدادات عند إزالة البرنامج تظهر كرمز {cm:...} بدل النص العربي.

ملاحظة خصوصية:
- متابعة الكتابة تتم في الذاكرة فقط، ولا تُحفظ أو تُرسل. تُمسح عند تغيير النافذة
  أو النقر بالماوس أو الضغط على Enter. ولا تعمل داخل MiftahFix نفسه.
  يمكن إيقافها بإلغاء الخيارين في الإعدادات > التحويل.

المطوّر والحقوق:
- المطوّر: مصطفى كامل — Mustafa Kamil، والبرنامج مفتوح المصدر بترخيص MIT (LICENSE.txt).
- نافذة "حول" جديدة: اسم المطوّر باللغتين، الترخيص، روابط فيسبوك والكود المصدري
  و"ادعم المطوّر" والترخيص، "صُنع بحب في العراق"، والحقوق بالعربية والإنجليزية.
- شاشة ترحيب عند أول تشغيل تشرح طريقة الاستخدام والخصوصية.
- المثبّت باللغتين (عربي/إنجليزي): اسم الناشر، رابط الدعم، صفحة الترخيص بلغة
  المستخدم، صفحة تعريف بالبرنامج قبل التثبيت، سطر المطوّر في صفحتي الترحيب
  والانتهاء، وخيار لزيارة صفحة المطوّر بعد التثبيت. يتطلب Inno Setup 6.4.1+.
- خصائص ملف البرنامج (Properties > Details) تعرض اسم المطوّر وحقوق النشر.
- README.md لصفحة المشروع على GitHub.

لنشر تحديث لاحقاً:
  1. أنشئ مستودعاً على GitHub باسم MiftahFix.
  2. ارفع المثبّت في Release جديد واجعل اسمه (Tag) مثل v1.2.0.
  3. كل من لديه البرنامج سيصله إشعار تلقائياً.

للتجربة:
  taskkill /F /IM MiftahFix.exe
  dotnet build
  dotnet run
